NEXT STORIES — SITE INICIAL
===========================

ARQUIVO
- index.html: site completo, responsivo e pronto para personalizar.

ANTES DE PUBLICAR
1. Abra index.html em um editor de texto/código.
2. Procure por: const DISCORD_INVITE = "";
3. Coloque o link de convite do seu servidor Discord entre as aspas. Exemplo:
   const DISCORD_INVITE = "https://discord.gg/SEUCONVITE";
4. Salve o arquivo.
5. Revise textos, preços, planos e formas de contato. Nenhum preço foi inventado neste modelo.

COMO PUBLICAR GRATUITAMENTE PELO ANDROID (OPÇÃO: GITHUB PAGES)
1. No navegador do celular, acesse https://github.com e crie uma conta ou entre.
2. Crie um repositório público chamado next-stories-site.
3. Use Add file / Upload files e envie o arquivo index.html deste pacote.
4. Abra Settings do repositório → Pages.
5. Em Build and deployment, selecione Deploy from a branch.
6. Escolha a branch main e a pasta / (root), depois Save.
7. Aguarde a publicação. O endereço aparecerá na própria página Pages, geralmente:
   https://SEU-USUARIO.github.io/next-stories-site/
   O endereço real depende do seu usuário do GitHub.

COMO FUNCIONA A COMPRA
- Os botões preparam uma mensagem de pedido.
- O cliente precisa conversar com você pelo Discord.
- Você confirma manualmente preço, disponibilidade e prazo.
- Envie os dados de Pix apenas depois de confirmar o pedido.
- Confira o pagamento na sua conta antes de entregar.
- Este site não processa pagamentos, não armazena pedidos e não confirma Pix automaticamente.

OBSERVAÇÃO
O link do Discord precisa ser configurado no código antes de publicar. Para manter a segurança,
não coloque senhas, tokens de bots, chaves privadas ou dados bancários no HTML público.
